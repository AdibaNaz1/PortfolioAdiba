# 🌐 PortfolioAdiba

A modern and responsive personal portfolio website showcasing my skills, projects, experience, and journey as a **Full Stack Web Developer**.

## ✨ Features

- 🎨 Modern and responsive UI
- 📱 Mobile, tablet, and desktop responsive design
- 👩‍💻 About Me section
- 🛠️ Skills & technologies section
- 🚀 Projects showcase
- 📄 Resume section
- 📬 Contact section
- 🔗 GitHub and social profile links
- ⚡ Smooth scrolling and interactive UI
- 🎯 Clean and user-friendly design
- 🦶 Responsive footer

## 🛠️ Technologies Used

- **HTML5**

- **JavaScript**
- **React.js**

- **Vite**

- **Git & GitHub**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/AdibaNaz1/PortfolioAdiba.git
```

### 2. Navigate to the project

```bash
cd PortfolioAdiba
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
